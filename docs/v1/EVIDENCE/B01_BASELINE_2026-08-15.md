### Falla reproducida

`tests/test_app_smoke.py::test_health_endpoint_is_registered_under_api_prefix`

El test asume que todos los elementos de `app.routes` tienen atributo `path`. Con la versión de FastAPI/Starlette instalada desde dependencias sin fijar, aparece un elemento `_IncludedRouter` sin dicho atributo y la prueba falla con `AttributeError`.

La línea base no decide todavía si se debe adaptar el test o fijar versiones. Esa decisión técnica corresponde al bloque de corrección posterior a revisar compatibilidad.

### Advertencias observadas

- Configuración Pydantic basada en `class Config`, deprecada desde Pydantic v2.
- Uso de `datetime.utcnow()`, deprecado en Python reciente.

## Riesgos confirmados por B01

1. Las dependencias backend no están fijadas a versiones reproducibles.
2. La guía de pruebas backend no especifica variables ficticias mínimas.
3. La prueba smoke actual no es compatible con la combinación más reciente instalada.
4. Falta un entorno Flutter para validar el frontend.
5. Falta Docker para validar las imágenes.
6. La validación iOS necesitará macOS/Xcode o CI macOS.
